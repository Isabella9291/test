# 创作约定与第一版范围

## 保持的方向

最终代码保存在 Isabella9291/test，使用 p5.js。三位成员分别负责时间、Perlin noise 与 randomness、用户输入，每项机制独立脚本。用户负责噪声与随机性，以此为重点。目标为 HD 标准，兼顾视觉、模块化、效率、注释、引用、AI 声明与真实个人提交。

以第六张参考为主要构图依据：接近正上方俯视，摊开的古老西方故事书占画面大部分，暖色旧木桌、偏黄旧纸、深棕磨损皮革。整体自然、有艺术感，像儿童童话绘本，同时带一点体积和厚度。后续持续调整，不把最初参考当作最终定稿。

## 完整交互意图

1. 开场书闭合，点击书扣展开。左侧翻页随机刷新羊群；右侧翻页切换四季。
2. 羊的数量、位置、大小各异，影子随尺寸变化。约 1/3 或 1/4 有狼影，其余普通影子。
3. 羊能看向鼠标，狼影张嘴或举爪。长按羊毛膨胀，松开化为云升起。
4. 云可拖动，松开继续噪声漂移。过一会儿碎成星点消失；部分随机降雨，落雨处生羊，新羊出现与云消散同步。
5. 春夏秋冬的树和景观不同，冬季飘雪。空白场景上拖变白天，下拖变夜晚；白天横向移动鼠标改变投影。夜晚不能全黑，羊眼随机彩色微光。
6. 左上角录音带可部分在画外，但播放和切歌区域必须可操作。固定几首音乐，唱片播放时转动。
7. 音乐仅为行为开关，不随节拍分析：夜间随机跳跃，各羊高度和时机不同且有界；白天狼影和所属小羊追逐，随机小圈/往返，避开其他羊。

## 第一版选择，可继续修改

- 羊毛化成云之后，原羊从草地移除。
- 狼影采用 28% 的独立概率，每页并非严格固定比例。
- 白天采用每只狼影羊独立的小型椭圆追逐路线，尚未增加左右往返的第二种路线。
- 季节通过翻页事件切换并按时间过渡；昼夜额外按 120 秒自动循环，保证时间机制不只依赖鼠标。
- 云与粒子有限，结束后回收，避免长期运行后无限增长。
- 音乐是三段原创合成旋律，未放入最终歌曲文件。
- 近俯视草地上方的云作为书中魔法漂浮，未使用透视天空或真正的 3D 立体书。
- 开书和翻页为简化二维动画，需要根据反馈精修；材质也尚未达到参考图的绘画细腻程度。
