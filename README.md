# The Sheep

An enchanted field journal · 一本会呼吸的羊群故事书

用 **p5.js** 绘制的交互绘本。深棕古书打开后，羊群、狼影、云、四季和昼夜在泛黄的书页上活动。当前为第一版可运行原型，后续根据团队反馈调整构图、笔触和交互。

## 运行

不需要构建，也不需要安装运行时 npm 依赖。p5.js 1.11.3 已保存在 `vendor/`，离线也能加载。

```sh
cd /workspace/test
python3 -m http.server 8000 --bind 0.0.0.0
```

在浏览器中访问服务器的 8000 端口。也可以用 VS Code 的 Live Server 打开 `index.html`。需支持 Canvas 2D 和 Web Audio 的现代浏览器。音乐只在用户点击后启动。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击封皮书扣 / Enter | 打开故事书 |
| 左下页角 / ← /「新的羊群」 | 翻页并重新生成羊群 |
| 右下页角 / → /「下一季节」 | 春夏秋冬循环，树冠、草地、花与雪随季节变化 |
| 悬停或短按小羊 | 不再触发抬头或狼影动作 |
| 长按小羊至少 0.6 秒再松开 | 羊毛膨胀并释放云朵；原小羊从草地消失 |
| 拖动云朵 | 改变云的位置，松开后继续自然漂浮 |
| 在草地空白处上下拖动 | 向上变白天，向下变夜晚 |
| 白天环绕移动鼠标 | 改变影子的方向和长度 |
| N /「昼 / 夜」 | 平滑切换昼夜，手动设置保留 45 秒 |
| 等待 | 昼夜自动以 120 秒周期流转；云在 16–25 秒后消散 |
| 录音带播放键 / M | 音乐开关；白天狼影羊群追逐，夜间羊群独立跳动 |
| 录音带小箭头 / T | 切换三首固定的原创合成旋律 |
| H /「操作说明」 | 显示或隐藏操作说明 |

支持触屏长按与拖拽。每次打开页面用当前时间产生新种子，翻页继续推进随机序列。调试时可在地址后加 `?seed=1927` 来复现相同的初始羊群。

## 技术与模块

| 文件 | 职责 |
| --- | --- |
| `js/sketch.js` | p5 生命周期、缩放和模块整合 |
| `js/book-scene.js` | 缓存木纹、皮革、纸纹、季节画面；绘制书、桌面和摆件 |
| `js/flock.js` | 小羊与狼影绘制、羊群边界与间距保护 |
| `js/perlin-mechanic.js` | 随机羊群、云的噪声风场、随机降雨、同步生羊与云消散、星点粒子 |
| `js/time-mechanic.js` | 开书与翻页计时、四季过渡、120 秒昼夜周期、手动时间覆盖 |
| `js/input-controls.js` | 鼠标、触屏、键盘与按钮；区分短按、长按、拖云和调节昼夜 |
| `js/music-box.js` | Web Audio 原创旋律与播放状态，不分析振幅或频率 |

**Perlin noise 与 randomness：** `noise()` 是连续风场，云每帧从相邻位置采样，不会随机瞬移。独立的 32 位随机数生成器用于数量、位置、尺寸、狼影概率、云寿命、降雨与个体差异，避免绘制纹理时的随机采样影响交互。狼影概率为 28%，实际数量会波动。雨云在最后 4 秒中，用同一个进度值控制云的透明度与新羊尺寸。眼睛颜色及跳跃参数也各不相同。

**Time-based：** 没有用户输入时昼夜也持续循环；开书、翻页、季节颜色过渡、飘雪与云生命周期按秒推进。`deltaTime` 让时间不依赖帧数，切回后台页面时限制单帧步长以避免突然跳变。

**User input：** 每次按下只进入一种交互，优先判断录音带、页角、云、小羊、空白草地。逻辑坐标统一为 1440×1000，缩放与交互坐标同步换算。

绘画质感通过透明笔触、纸纹和不规则边缘实现。书本体积通过渐变、页缘层次和投影实现，使用 Canvas 2D。静态纹理预先缓存；云最多 14 朵、羊最多 45 只，结束的粒子会回收。小屏幕等比例缩小，建议横屏桌面体验。

## AI 使用声明

本原型使用 **OpenAI ChatGPT / Codex** 协助：整理需求、生成与调整 p5.js 场景绘制、实现 Perlin noise 云运动与随机生命周期、交互状态、Web Audio 合成旋律、浏览器检查和文档。各 JavaScript 文件顶部均有对应注释。

代码工作方式见上方技术说明；团队需理解代码，按课程要求说明自己做出的设计与改动。三段音乐是代码定义的原创音符序列，通过振荡器和音量包络播放，没有使用外部录音。

## 外部代码与资料

- [p5.js](https://p5js.org/) **1.11.3**：绘图框架，项目本地附带；许可证见 `vendor/p5-LICENSE.txt`。
- [p5 noise()](https://p5js.org/reference/p5/noise/)：连续噪声风场。
- [p5 randomSeed()](https://p5js.org/reference/p5/randomSeed/)：可复现随机过程的概念；实现使用独立 LCG 状态。
- [p5 deltaTime](https://p5js.org/reference/p5/deltaTime/)：基于经过时间的动画。
- [p5 mousePressed()](https://p5js.org/reference/p5/mousePressed/)：输入事件。
- [MDN Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)：旋律合成、振荡器与音量包络。这项技术超出 p5 基础，已在代码解释并引用。
- [Playwright](https://playwright.dev/)：开发时的浏览器检查，不参与作品运行。

未复制参考作品的源代码。其余实现由上述 AI 辅助流程生成并由后续团队开发调整。

## 浏览器验证

先启动服务器，另开终端：

```sh
npm ci
npx playwright install chromium
npm test
```

也可以使用已有 Chromium：

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

检查实际点击开书、短按与长按、拖云、噪声漂移、随机雨云的生羊生命周期、页角操作、四季循环、昼夜切换、音频节点调度、切歌暂停、缩放和说明按钮。生命周期测试会加速推进时间。自动化验证音频节点调度，不能代替人耳试听。
